# Hybrid Search 与 Re-ranking

纯向量检索擅长找语义相近的内容，但有时会错过精确关键词，例如产品名、函数名、错误码或专有名词。关键词检索擅长精确匹配，但不理解同义表达。Hybrid Search 会把向量相似度和关键词分数结合起来。

一种简单做法是：先计算向量相似度，再计算 query 和 chunk 的关键词重叠比例，最后把两者加权求和。比如总分可以等于 0.7 乘以向量分数，加上 0.3 乘以关键词分数。这样既保留语义匹配，又照顾精确词命中。

Re-ranking 是另一种常见优化。第一阶段先召回较多候选 chunk，例如 top 20；第二阶段用更强的模型或规则重新排序，选出最终 top 3。Re-ranking 通常比只调 top-k 更有效，但成本也更高。

本示例实现 Hybrid Search，不额外实现模型级 Re-ranking。这样可以在没有外部 API 的情况下观察检索质量如何变化。
