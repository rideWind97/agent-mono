# RAG 评估

RAG 不能只看单次演示是否回答得像样，应该准备一组测试问题评估检索质量和回答质量。最小测试集可以包含 10 条 QA，每条记录问题、期望命中的文档、期望答案关键词。

检索命中率是入门阶段最重要的指标之一。比如 top-k 检索结果里包含期望文档，就记为命中。10 条测试中命中 7 条，命中率就是 70%。这不能代表最终答案一定正确，但能快速发现 chunking、embedding 或检索策略的问题。

回答质量也要检查是否引用来源。一个可靠的 RAG 回答应该说明依据来自哪些文档或 chunk。如果没有检索到足够证据，回答应该说“知识库中没有找到依据”，而不是编造。

实际项目还会评估 faithfulness、answer relevance、context precision 和 context recall。学习阶段可以先人工检查：答案是否来自文档、是否命中关键事实、是否带引用、是否在证据不足时拒答。
